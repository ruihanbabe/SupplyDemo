# F32 Contract：CRM 业务域、会话、Kanban 与受控提案

> 状态：进行中｜类型：深度｜里程碑：M1｜spec：§1.2、§2.6

## 目标

由 Python 提供组织隔离的客户、联系人、商机、会话、任务和不可执行 Proposal；Next 只转发和展示。

## 保留基础

`supabase/migrations/0005_f32_crm.sql`、`0006_f32_crm_commands.sql`、`0007_f32_crm_interactions.sql`、`0008_f32_crm_review.sql`、`0011_f32_crm_scope.sql`、`0012_f32_crm_audit.sql` 与 `supabase/tests/f32_crm.sql` 保留为 PostgreSQL/RLS 基础。它们必须在 Python 服务接入时重新验证。

## 待实现

- Python CRM Repository、领域命令与 FastAPI 路由；
- scope、Proposal 内容哈希、目标版本冲突和审计的 Python 路径；
- 组织范围的读取和人工录入。

## 边界

- 模型只能创建不可执行 Proposal，不能直接写 CRM 事实。
- Proposal 批准后的执行属于 F41；渠道发送属于 F37。
- 不把供应链、库存、采购或排产逻辑带入 CRM 服务。

## 验收证据

Python 离线测试与真实 PostgreSQL 测试必须证明：跨组织/跨 scope 拒绝、目标版本冲突显式处理、Proposal 不自动执行、审计不记录正文。
