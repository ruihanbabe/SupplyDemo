# F30 Contract：v0.6 产品基线与遗留清理

> 状态：已完成，待用户验收（2026-10-23）｜类型：最小｜里程碑：M0｜spec：§0.4、§3、§5

## 目标

以 Python API/Worker/Harness、PostgreSQL/RLS 和无状态 Pi sidecar 为唯一产品基线，移除早期单租户 Harness 的实现、测试、配置、Contract 与叙事。保留旧 Alembic migration 作为数据库历史，但不将它们视为可复用产品能力。

## 做什么

1. 删除早期 Feature 的实现、测试、配置、Contract、样例数据与旧交接材料。
2. 从 `features.json`、`spec.md`、保留的 Contract、Makefile 和 HANDOFF 移除已删除 Feature 的依赖或能力声明。
3. 保留 `alembic/` 的历史 migration，明确其维护用途；当前产品 schema 仍只由 `supabase/migrations/` 和各 Feature `*-migrate` 目标管理。
4. 验证保留的 F31+ 源码、测试与命令不导入已移除模块。

## 不做什么

- 不重写已删除能力的替代实现。
- 不删除或重写历史 Alembic migration。
- 不把本轮清理当作任何产品能力的验收。
