# F42 Contract：Harness 迁入——模型、编排、上下文与 Specialist 接入 PiRuntimeAdapter

> 状态：等待用户验收｜类型：深度｜里程碑：M2｜spec：§2.2、§2.4、§3.1

## 目标

由 Python Harness 组装任务图、上下文、工具白名单和 Gateway 调用，并经 F35 的 Python `PiRuntimeAdapter` 执行产品 Agent turn。

## 本轮已确认范围

- Python `Harness` 只接受已验证的组织、Run、Case、任务摘要、事实引用与受限工具定义；不接受自由系统提示、角色、凭证或任意工具描述。
- Python `PiRuntimeAdapter` 通过实际 Node 子进程执行协议 v1：stdin/stdout 仅允许一行一个 JSON 对象，事件为 `turn.started`、`tool.call`、`turn.completed`、`turn.failed`。未知版本、未知字段、重复/乱序事件、超长行及 secret-like 字段一律失败关闭。
- 工具只可由 Python 注册表按精确名字分派；本轮只允许只读 `supply.impact` fixture/领域读取。Node 只能收到工具结果，不能收到数据库 URL、组织/渠道/Provider 凭证、终端、文件或 shell 能力。
- Adapter 将已验证的事件和最小 checkpoint 写入调用方提供的 F40 `TraceRepository`；checkpoint 只保存协议版本、事件序号、完成状态和工具调用 ID，恢复时只能由 SQL Trace 重建，不能使用本机 JSONL 文件。
- 用固定协议 sidecar 夹具验证真实 Python↔Node 子进程 IPC、工具回传、拒绝非法协议、取消/异常清理及本地 PostgreSQL Trace 哈希链。它不是 Pi 上游或模型调用；真实 Pi 上游接入、F34 Gateway/计量、F35 Worker claim/lease/retry 和 F33 SSE 仍各自保持未完成。

## 验收

- 离线：协议 schema、工具白名单、敏感字段拒绝、乱序/未知事件拒绝、子进程退出清理与 checkpoint 内容测试；`make f42-check`。
- 本地真实场景：运行真实 Node sidecar、Python Adapter、受限 `supplyagent_api` RLS 事务与 F40 SQL Trace，验证哈希链及跨组织不可读；`make f42-integration-test`。
- 不调用真实 Provider、Pi 服务、渠道、ERP 或供应商 API；不把固定 sidecar 当成上述服务已接通的证据。

## 边界

- Node sidecar 只适配锁定的 Pi 上游协议；没有数据库、Provider、渠道或组织密钥。
- Pi 的本地 JSONL 不能替代 SQL Trace、长期记忆或恢复事实。
- 不把 Pi Coding Agent 的终端、文件或 shell 工具变成产品能力。
- F42 不实现 F35 HTTP 入队/Worker、F34 Gateway、F36 Specialist 知识检索、F41 提案/副作用或 F33 SSE；这些依赖不因本轮测试被宣布完成。
