## 目标

实现图中的 CRM/Agent 工作台和运行可视化；页面是受权限约束的事实投影，不持有运行逻辑或绕过审批。

## 2026-10-10 架构重基线

保持 Next.js/React Workbench，但所有业务读取、审批命令和 SSE 都由 Python API 提供；Next BFF 只能同源转发。前端构建、lint 与“浏览器不得直连 SQL/凭证”的边界检查继续保留，并新增检查：前端不得导入 Python 领域实现以外的服务端运行时，也不得把 SSE 重放逻辑复制到浏览器或 Next Route Handler。

## 做什么

1. Next.js/React 工作台提供客户、商机 Kanban、供应链案子、任务、运行时间线、Artifact/证据摘要、审批收件箱和组织配额视图。
2. SSE endpoint 支持 `Last-Event-ID`，先补 Event Log 再实时推送；事件按组织、scope 和脱敏策略过滤。
3. 审批页显示草稿、预演、证据、目标版本、授权有效期及拒绝/恢复操作；审批动作走 F31 API 和 F37 令牌入口。
4. 配额面板读取 F34 的组织级计量投影，不自行估算或暴露凭证。
