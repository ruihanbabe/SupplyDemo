# F37 Contract：人工决策、受控写入、发送账本与 WhatsApp/飞书渠道

> 状态：2026-10-28 顺序授权实施本地加密发送/回执/对账单元；真实WhatsApp/飞书另行接入验证 ｜ 类型：深度 ｜ 里程碑：M3 ｜ spec：§0.3、§2.7、§2.8

## 当前本地实施单元

复用F41 Proposal/Approval/Job/Execution，扩展message_send人工草稿，密封正文/接收目标后落库；审批、当前权限/版本/opt-out/服务revision/证据重校验后，Worker写发送意图再调用受控Adapter。账本区分prepared/sending/accepted/delivered/failed/reconciliation_required；未知结果先lookup，不盲目重复发送，accepted不等于送达。加密inbox接收经验证的fixture回执，事件ID幂等、相同ID变更内容拒绝。

唯一启用实现为隔离SQLite的FixtureAdapter，持久logical_action_id去重并支持lookup，测试真实独立后端提交后丢响应/Worker重启的对账。不是WhatsApp/飞书模拟成功冒充实接；这些名字不开放发送，真实签名/加密协议、账号、会话接线仍保留目标并需G5授权。Pi/Next不持有密钥或执行能力，API不直接发送。

加密采用cryptography Fernet，不自制密码算法；固定可选依赖requirements.channels.lock.txt，仅在f37-setup显式装配。必要性是当前环境无加密实现、F37要求私有inbox/outbox不可明文落库；替代明文不满足边界。成本是cryptography/cffi/pycparser及受控服务端密钥；清洁Python3.11环境已验证加解密/错钥拒绝。主选46.0.7 wheel，避免当前50系列在本机源码构建；参考官方PyPI及Fernet文档，未声称这是全平台/生产安全验收。

新增0044只在克隆追加，默认无密钥/未启用政策时拒绝草稿或执行；发送Adapter必须由可信Python注入。验收未审批/过期/撤权/opt-out/版本变更拒绝，发送前/后崩溃、迟到结果/重复回执、未知结果与跨组织隔离；不调用任何真实网络渠道。

加密人工提案/API解密审阅、审批入Job、发送意图、独立SQLite接收方幂等/重启lookup、签名回执与加密inbox、取消后迟到事实均已接线。`f37-check` lint与2项离线通过，最新`make check`为232 passed/91 deselected。克隆集成保留全部11种场景及原断言：最新10 passed/1 failed，lost_response首次领取返回idle；此前全量86 passed/3 failed，含unknown第三代领取idle和两项Memory领取idle。不能宣称专项或全量全绿，Feature保持in_progress等待后续验证。

## 目标

把图中的“动作分级与人工边界”“审批发送”“渠道事件”实现为同一条不可绕过的受控副作用链，覆盖 CRM 更新、采购提交和消息发送。

## 2026-10-10 架构约束

Proposal、Approval、Execution、SendLedger、渠道 webhook 验证及执行 Adapter 均属于 Python API/Worker；Next 只呈现审批收件箱并转发人工决定。渠道回调不能经 Next Route Handler 直接写 SQL，必须进入 Python 的验证、幂等和 Trace 链。

## 做什么

1. 统一 Proposal、Approval、Decision、Execution、SendLedger：提案绑定内容哈希、目标版本、组织、scope、风险、证据、有效期和幂等键。
2. 人工可批准、拒绝、要求恢复；批准签发不可由模型构造的短期令牌。所有 R1/R2 执行前重校验对象版本、角色、opt-out、service revision、证据和草稿哈希。
3. CRM 更新、采购草稿/提交遵循 BL10 的待实现统一门控；写操作失败/过期转为反馈和重规划，不能静默重试为成功。
4. WhatsApp Adapter：受控接收客户事件、创建/关联会话和回复提案；发送仅从已批准 SendLedger 执行。
5. 飞书 Adapter：加密 inbox/outbox、内部协作事件和 SQL Job；它不能代表客户渠道、不能绕过客户发送审批。

## 不做什么

- 不执行真实 WhatsApp/飞书连接、读取真实会话或发送消息，除非用户另行授权。
- 不永久授权某个 Run；不允许 Agent 直接调用 Adapter 的发送接口。
