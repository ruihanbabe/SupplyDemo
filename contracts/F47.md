# F47：版本化 BOM 关联与报价时效 Specialist

状态：2026-10-23 用户授权实现 BOM 版本关联和报价时效 Specialist；代码及本地验证已完成，等待用户验收；业务库迁移待确认。记忆治理决策见 F48。审批与渠道执行按用户要求暂缓。
引用：spec §0.3、§1、§2.5、§2.6；承接 F46 四场景模拟数据。只做版本化领域事实、只读工具及 Specialist 运行，不做 CRM 动作执行/采购提交/发送。

## 领域数据与追加清单

0026 追加四类关系表：组织产品、不可变 BOM 修订、商机 BOM 绑定、不可变报价修订。业务库仍待用户确认清单后统一应用；只在克隆库验证。

- `app.catalog_product` 产品：组织内产品代码/名称及对象 scope。
- `app.bom_revision` BOM 修订：产品、revision、schemaVersion=1 的 lines、数据库生成内容哈希、synthetic/official/user_supplied 来源、可撤回状态。每条 line 固定 lineKey、manufacturer、mpn、quantityPerUnit；正数量、唯一行号、受限大小。版本是原子不可变文档，业务关联为关系表；不把产品/BOM 关系塞入权限 scope。
- `app.opportunity_bom_binding` 商机绑定：同组织 opportunity、bom_revision、units、required_on、binding_version。任一需求/版本改变均推进绑定版本；不自动绑定“最新 BOM”。
- `app.commercial_quote_revision` 报价修订：opportunity、bom_revision、reference/revision、customer_offer 或 supplier_offer、可选 BOM 行、数量、价格/币种、签发与有效截止、预计发货和确认到货、scope、来源及撤回。供应报价必须指向所选版本中存在的行；时间和价格不能由 LLM 生成。

BOM/报价内容发布后不可改写，允许显式撤回；报价 scope 可调整并在读取时重新校验。纠正内容用新版本；绑定不允许删除再重建以重置版本号。外键和 RLS 防止跨组织/对象读取。初始导入由受保护测试种子证明，本轮不新增绕过审批的业务用户写命令。

## 执行与状态

新商业调查入口固定 BOM 修订 ID 和绑定版本，继承 F46 的分析时间及 Case 全料号范围。模型不能选择其他版本/组织；等待执行期间绑定变化时要求新调查。

BOM 数量由 Decimal 计算 units × quantityPerUnit，相同 MPN 合并；BOM 与 Case 料号集合不一致时不能静默做部分计算。供应覆盖以绑定商机的 BOM 派生需求、可见库存和在途收货计算，不重复叠加旧的手工供应需求行。结果明确是本商机覆盖投影，不是全组织可同时承诺的库存分配或排产结果。

报价时效先由 Python 确定性分类：未到签发生效时点、有效窗口内、到期（截止瞬间即到期）、期限未知、撤回、被已签发新修订替代、版本不匹配。不同报价来源不天然冲突；缺报价仅指当前可见范围。数量或交期未确认保留未知，有效报价不等于锁货、确认到货或获准采购。

新增 `quote_validity` Specialist，精确绑定只读报价证据工具；与独立事实/政策/供应调查并行，商机诊断再读取前序结果。输出沿用 F36 Claim/Citation/unknown/conflict，实际观测私有保存；引用检查不冒充语义验收。Replay 清楚标记，真实模型另行授权。

查询旧结果时重验 BOM/报价来源权限与撤回状态；事实版本和绑定变化必须可辨，不能把旧回答描述成当前有效报价。

## 验收与开关

- BOM 版本不可原地改写，500 套需求从固定 revA 计算；revB 不影响已绑定 revA，改绑会推进版本并拒绝旧排队任务。
- 报价边界、期限未知、未来签发、撤回、修订替代和版本不匹配；价格 Decimal 精确，不将预计发货当确认到货。
- 真实 PostgreSQL/RLS + Pi Replay 执行 quote_validity，来源/权限/旧结果撤回门禁有效；旧 F45/F46 路径兼容。
- 商业节点默认关闭，入口 `SUPPLYAGENT_COMMERCIAL_NODES_ENABLED=1` 才启用；已接单任务绑定模式与来源版本，不因入口开关切换而降级。
- make check、商业单元 check/integration；不调用真实 Provider/分销商/渠道，不应用业务库迁移。

不增加外部服务或新依赖。Mem0 此轮仅更新产品 Contract；F41/F37 继续暂缓，不通过测试夹具的事实推进声称审批/渠道已实现。
