## 目标

由 Python 将 Run、Event、Artifact、计量和回放写为组织范围的 SQL 审计事实；Next 只转发 SSE 或渲染读取结果。

## 边界

- 浏览器、Pi 和 Redis 不是 Trace 权威写入者。
- Trace 不保存密钥、原始 BYOK 或未脱敏客户正文。
- 回放不得触发真实 Provider、渠道或供应商。
