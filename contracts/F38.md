## 2026-10-10 架构约束

Compose 交付以 `web`、`api` 和 `worker` 为独立进程；`pi-sidecar` 是可替换的无状态 Agent Engine Adapter。Eval 以 Python Product Harness、API 和 Worker 为被测对象，Next 只做展示层验证；不得把旧 TypeScript 领域实现作为生产路径。

## 做什么

1. SQL Event Log/Artifact/计量是权威 Trace；支持按 Run/Case/Event-ID 查询、SSE 回放、脱敏导出、数据/全回放与分叉。
2. 可选 Langfuse/OTLP 适配器仅转发脱敏 span、score 和 trace 关联号；不可替代 SQL 审计、不可上传凭证或原始私有内容。
3. Eval 覆盖 CRM 与供应链：结果/过程/成本、RLS 隔离、权限越权、审批前后变化、Worker 崩溃恢复、重复消息、渠道 opt-out、引用与污点边界。
4. 提供 Docker Compose 的 Web、API、Worker、PostgreSQL、Redis 和本地依赖启动路径；演示使用固定样例/回放，明确真实集成状态。
5. 交付清单列出配置、迁移、最小启动命令、测试命令、演示回放、已接通与未接通 Provider/渠道。

## 不做什么

- 不以 Langfuse 页面或静态截图替代可执行 Eval。
- 不在交付中放入生产凭证、真实客户数据或未授权渠道记录。
