# F06 Contract：Session 事件日志与 Artifact

> 状态：已写，按用户 2026-09-29 授权直接实现、事后统一验收 ｜ 类型：深度② ｜ 里程碑：M1 ｜ spec：§5.1、§5.5（哈希链）｜ 依赖：F01

## 目标
Agent 侧的唯一事实来源：只追加、带哈希链的事件日志；不可变、有版本、记依赖的 Artifact；外部数据变化或过期时沿依赖图把下游全部标为失效并通知所属案子；案子状态、Artifact 状态都从日志投影得出，不另存可修改的状态表（spec §5.1）。

## 做什么（`src/session/`）
1. **事件日志**：每个事件带运行号、序号、案子号、模拟日、真实时间、执行者、类型、内容、实体键（料号/板/工单/订单/运单/分销商/文档，spec §5.2）、`caused_by`、去重键、上一事件哈希与本事件哈希。
   - 哈希链（spec §5.5 防篡改）：`hash = SHA-256(prev_hash + 规范化 JSON(除真实时间外的全部字段))`。真实时间不进哈希，使全回放（§5.12）的哈希链可与原运行逐条比对。
   - 去重：带去重键的事件重复追加时返回原事件（spec §5.2"事件按 ID 去重，允许重复投递"）。
   - 链校验 `verify_chain()`；按案子、类型、序号区间读取；沿 `caused_by` 倒查因果链。
2. **Artifact**：`(artifact_id, version)` 唯一，内容 JSONB 不可变，记内容哈希、所属案子、产出事件序号、模拟日。依赖两类：其他 Artifact 的某个版本；外部数据引用（如 `quote:element14:SKY13453`，带数据版本和按模拟日的有效期，粒度同 spec §5.1，不细到字段）。产出新版本即把旧版本投影为"被替代"。
3. **失效传播**：`invalidate_external(ref, new_version)` 与 `expire(day)`：找出依赖该外部数据旧版本（或已过期）的有效 Artifact，连同其下游（沿依赖图传递）全部写"失效"事件（带根因）；对每个受影响案子写一条"失效通知"事件（实体键含受影响 Artifact），供 F10 路由唤醒。确定性节点的自动重跑归 F21/F09，本 Feature 只负责标记与通知。
4. **投影**：Artifact 当前状态（有效 / 失效 / 被替代）与案子状态机（开启 → 规划中 → 执行中 ⇄ 等待（人工/到货/外部）→ 关闭（已解决/已放弃/已升级））都由日志折叠得出；非法状态迁移在追加前拒绝。
5. **存储**：一个 `SessionStore` 接口，内存实现（离线测试）与 Postgres 实现（迁移 `0003_session`：`session_event`、`artifact`、`artifact_dep` 三张表，均只追加）。
6. **消融开关**（spec §0.3）：`config/harness.yaml` 的 `ablation.invalidation_propagation`；关掉时外部数据变化与过期不产生任何失效（模拟"没有依赖图"的 Harness），供 F28 对照。

## 不做什么
- 事件路由、订阅、开案、合并（F10）；Runtime 重建上下文（F09）；反馈卡片（F14）；上下文摘要（F16）。
- 代表链与能力令牌（F11）、字段级污点标签（F13）：事件与 Artifact 各留一个 JSON 元数据字段给它们，本 Feature 不填。
- LLM/工具计量（F17）：计量表归 F17，与事件用事件序号关联。

## 验收证据
| # | 命令 | 通过条件 |
|---|---|---|
| 1 | `make check` | 离线测试覆盖：哈希链可校验、篡改任一事件即校验失败；去重；A2 例（报价变化 → SourcingQuote、Decision、PODraft 失效，PartProfile、VerificationReport 仍有效）；过期失效；案子状态投影与非法迁移拒绝；消融开关关闭时不失效 |
| 2 | `make migrate` | 多出三张表；三张表 UPDATE/DELETE 被拒 |
| 3 | `make test-integration` | Postgres 实现跑同一组场景，结果与内存实现一致（投影、失效集合、哈希链逐条相同） |

## 默认值（设计分歧时再问）
- 一次运行一条哈希链（跨案子共享序号），便于全局排序与全回放比对。
- Artifact 状态变化不改 Artifact 行，而是写事件；"被替代"由存在更高版本推出，不单独写事件。
- 只追加触发函数复用 F03 迁移里的 `env_append_only()`（报错信息带表名，与表无关）。
