## Q-01 · 首个真实供应数据源与凭据 —— 已冻结（2026-09-22）

**结论**：三家同时接入，均为只读产品查询：

| 分销商 | 认证 | 端点 |
|---|---|---|
| Mouser | API key（query string） | `api.mouser.com/api/v1/search/partnumber` |
| element14 / Farnell | API key（query string） | `api.element14.com/catalog/products` |
| DigiKey | OAuth 2-legged，token 只存进程内存 | `api.digikey.com/products/v4` |

凭据走 `SUPPLYAGENT_SUPPLIER_*`，只透传给 MCP 子进程（白名单按名字列出）。

**冻结条件的三项证据**：凭据到位 ✓；字段映射按实测响应校准而非按文档猜测 ✓（三家的库存、交期、价格形状各不相同，见 `mcp_servers/supplier/adapters/`）；授权的只读调用 ✓（`make probe-suppliers`，IRFZ44NPBF 与 TC4420EPA 各跑通一次）。

**仍然成立的约束**：只做采购信息读取，不调用任何下单接口。DigiKey 的 sandbox 主机前置了 bot 挑战、对普通客户端一律 403，因此走生产主机；响应头带 `x-ratelimit-remaining`，进程内另有按家的令牌桶。

## Q-04 · 官方资料的寻址策略与许可边界

**待定**：

1. 寻址策略链的优先级与放弃条件（厂商 URL 模板 / 文档缓存 / 分销商返回的 datasheet 链接 / 厂商站内搜索）；
2. 抓取礼节：速率上限、`robots.txt` 遵守范围、缓存保留期；
3. 文档原文的留存许可边界。

已实测事实见 `docs/product/requirements.md` §9，此处不复制。要点：瓶颈在寻址而非解析；厂商间差异显著，存在站点拒绝抓取与公开索引失效的情况。

**当前对策**：只对可公开访问且明确允许下载的资料取证；缓存本地化并用于回放；无法寻址时输出显式失败态，不绕道第三方镜像站。

**冻结条件**：策略链顺序与放弃条件确定 + 速率与保留期确定 + 许可边界确认。

## Q-05 · 阈值取值与生命周期枚举映射

分工已由 D20 冻结（阈值归程序、进 `business_rule`）。**本条待定的是取值本身**：

1. 各条阈值规则的具体数值与分级（第一期只有「交期 > 8 周」，取值已定，其余未定）；
2. 生命周期阶段的枚举取值，以及各厂商原文表述到该枚举的映射。

厂商表述不统一是实测事实：ST 用 `Active - Product is in volume production`，TI 用 `ACTIVE`，其他厂商另有 NRND / Last Time Buy / Obsolete / Mature 等说法。映射表本身就是需冻结的契约，且必须保留原文而非只存归一化值。

**当前对策**：证据保存原文表述与定位，不强行归一化；`RiskEvent` 只输出事实型标签，不生成综合评分。

**冻结条件**：取值与映射表由用户确认，且每个厂商的映射有对应验收用例。

## Q-07 · 告警工作台的形态

**已部分冻结**：对话入口的技术栈定为 **FastAPI 直接托管的原生 HTML/JS**，同源、无构建链。界面为左右两栏——左栏是模型写的文字，右栏是工具返回的权威数值，这条界线是硬的（不变量 2）。

**仍待定**：以告警为中心的工作台（F09，第二期）的信息密度与分组方式。它与对话入口并存，不互相取代。

**当前对策**：只做对话入口；工作台不开工。

**冻结条件**：用户确认工作台的首屏形态。

## Q-09 · 跨币种价格如何呈现与比较

**由 Q-01 接通后暴露**：三家返回三种币种——Mouser 随账户地区给 RMB，element14 随 store 给 GBP，DigiKey 按 locale 给 USD。BR-03 要求有金额必须有币种，且无币种的裸数字不得参与比较。

**待定**：

1. 是否统一到单一币种呈现（需要经核验的汇率来源，本系统目前没有）；
2. 还是保持各源原币并显式标注不可比；
3. element14 的 store 是否改为 `www.newark.com`（USD）以减少币种数——但 Mouser 的币种跟随账户地区，改不掉。

**当前对策**：各源原币并列，`prices_comparable=false` 时界面显式告知不可直接比价，不做任何未经核验的换算。

**冻结条件**：用户确定呈现方式；若选统一币种，须同时确定汇率来源、取得时刻与它自身的证据留痕。
