# 领域术语表

> **文档契约** · 类型：共享词汇契约 · 读取：首次进入项目时通读，之后定点查询
> 更新：领域对象或统一命名变化时
> 独占：术语及其业务含义
> 不收录：字段类型、业务规则、当前数据统计

## 业务对象

| 术语 | 含义 |
|---|---|
| BOM / 用料行 | 某产品版本的物料清单；一行是一种用料及其单件数量、位号与候选关系 |
| MPN | Manufacturer Part Number，器件身份的主要要素 |
| Candidate / 候选 | 用料行可接受的具体元件；多个候选**不表示**已证实技术等价 |
| Component / 元件 | 规范化的厂商与 MPN 身份 |
| 可分配量 | 按版本化规则计算的可用库存与合格在途 |
| 缺口 | 某一时点需求减去可分配量的结果，附规则版本，不可变 |
| Supplier Offer / 报价 | 带 SKU、数量、MOQ、包装、价格、币种、交期、时间与来源的观测 |
| Proposal / 采购建议 | 针对一次缺口计算生成的版本化建议；不等于库存占用或采购单 |
| Procurement Draft / 采购草稿 | 经审批后在外部系统创建的未提交单据；不提交、不付款 |

## 编排与执行

| 术语 | 含义 |
|---|---|
| Supervisor | 会话状态与意图路由的唯一持有者；不推理业务 |
| Graph 编排器 | 确定性 DAG 的调度者：并发、汇合、失败语义、预算沿边扣除 |
| Graph 节点 | 编排单位——「这一步要做什么」，运行时才存在 |
| **Worker** | 实现单位——「谁来做」，代码里只有一份。一个 Worker 会被调用多次 |
| Worker 形态 | `service`（纯确定性代码，不碰模型）/ `agent`（有独立 prompt、工具集、模型档位） |
| fan-out / fan-in | 并发展开 / 汇合校验。并发单位是「元件 × 核验类型」 |
| NodeResult | 节点产出：`ok` / `partial` / `not_found` / `error` 四态，不得合并 |
| 部分失败 | 汇合处有分支未成功。建议仍出但标注缺口，并抬高审批级别 |
| Run | 一次有持久状态的执行；可等待、恢复、取消与重放 |
| Human Gate | 等待人工补充、选择、审批或取消的状态；等待不是错误 |
| PermissionDecision | 对指定方案版本、内容哈希与动作范围的人工决定 |
| logical_action_id | 外部写操作的业务幂等键 |

## 证据与风险

| 术语 | 含义 |
|---|---|
| Evidence / 证据 | 带来源、取得时间、查询参数摘要、定位块与新鲜度的事实记录 |
| evidence_ref | 从建议或 `RiskEvent` 回指证据的稳定引用 |
| **RiskEvent** | 结构化风险事件。`source` 为 `rule`（阈值，程序判定）/ `model_judgment`（语义，模型判定）/ `collection_failed`（采集失败）——三者可信度不同，必须区分 |
| Unknown / 无法判断 | 证据不足时的**有效结论**，必须附缺失信息，不用臆测填补 |
| Provenance / 来源性质 | `real` / `cache` / `sample` / `replay`，防止把模拟数据冒充真实结果 |

## 模型与工具

| 术语 | 含义 |
|---|---|
| ModelBackend | 对具体模型服务的统一端口。形态分云端 / 本地 / 回放，与协议无关 |
| ModelCapabilities | 后端能力，由固定探针**实测**得出，不由手写声明代替 |
| 能力协商 | 请求所需能力后端不具备时显式拒绝，不删约束静默降级 |
| ReplayBackend | 从录音返回结果的后端，按请求内容哈希寻址，用于离线回归 |
| Tool Registry | 工具注册、schema、按场景与权限注入、调用分派的唯一入口 |
| Skill / MCP | 内部能力走进程内 skill，外部能力走 MCP——二者并存是刻意的设计对比 |
| trace_id | 贯穿入口、节点、模型、工具与持久化记录的关联标识 |

## 数据治理

| 术语 | 含义 |
|---|---|
| domdata | 原始只读数据层，不允许修订或补字段 |
| normalized | 从原始层确定性生成、供下游使用的规范化数据 |
| business_rule | PostgreSQL 中版本化的可变业务参数与阈值 |
| SSOT | 一个信息要素只在一个权威文档保存正文 |
| Feature | 可独立实现、验证和报告状态的交付单元 |
