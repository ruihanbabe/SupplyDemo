# 当前依赖与维护入口

精确 Python 环境版本见 requirements.lock.txt；Node 依赖分别由 frontend/ 和 pi_sidecar/ 的 package.json + package-lock.json 固定。命令仅在 Makefile 实现，服务拓扑以 compose.yaml 为准，环境变量见 .env.example。

| 用途 | 当前组件 |
|---|---|
| Python API/验证 | FastAPI、uvicorn、pydantic、python-dotenv |
| 产品数据库 | psycopg；PostgreSQL + RLS |
| 历史 public schema 维护 | Alembic、SQLAlchemy（同步 psycopg 驱动）；不管理 app 表 |
| 模型 HTTP | httpx；Pi 的官方协议 Adapter，不引入厂商 SDK |
| 知识文件导入 | pypdf |
| 离线验证 | pytest、ruff、compileall |
| Web | Next.js、React、Supabase Auth 客户端；无业务 SQL/Worker |
| Agent turn | pi-agent-core / pi-ai 0.73.1、typebox |

锁文件中仍有暂未直接使用的历史/开发依赖，本次未批准卸载或重建环境；不把锁文件的每个包都称为当前产品直接依赖。Redis 服务保留，但当前产品队列由 SQL 管理。

新增依赖先说明必要性、替代方案、成本和验证。依赖变更后在干净环境验证，再用 make freeze 固化 Python 环境；不要手删传递依赖的 lock 行。当前整理不改变任何已安装版本或锁文件。

F37可选渠道加密依赖独立锁定在requirements.channels.lock.txt，不替换既有主环境或Memory锁。使用cryptography Fernet；清洁Python3.11已验证加解密和错钥拒绝。仅受控Python处理私有密钥，默认无配置拒绝；安装入口f37-setup，不启用真实渠道。
