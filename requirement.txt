# SupplyAgent 当前环境与依赖台账

> 用途：记录“服务器上实际安装了什么”以及“项目准备安装什么”。

> 最后核对：2026-09-03（Asia/Shanghai）

## 当前解释器

- Conda 环境：`agent`
- Python：3.11.15
- 路径：`/root/miniconda3/envs/agent/bin/python`
- pip：26.1.2
- 环境性质：SupplyAgent 独立 Conda 环境
- 计算资源：8 CPU、43 GB 内存、RTX 3090 24GB；宿主终端 CUDA 可用，Codex 默认沙箱不映射 GPU 设备节点，需要时按开发切片申请单次授权

## 当前环境结论

- 已有 Python 3.11 独立环境，可直接作为当前开发环境。
- FastAPI、Qdrant Client、FlagEmbedding、Sentence Transformers、Torch 等已安装。
- 环境实测已有 `ragas==0.4.3`、`openai==2.53.0` 及其带入/共存的 LangChain、LangGraph 依赖；RAGAS仅用于离线评测，不改变MVP继续使用自研轻量Agent Runtime的架构决策。旧 Agent/API 原型仍暂作历史对照。
- 环境包含 CUDA 版 Torch。2026-08-04 宿主终端核验 `nvidia-smi` 与 PyTorch CUDA 正常，并使用 RTX 3090 完成法规向量入库；Codex 默认沙箱仍因设备隔离不可见。GPU 操作不设长期授权，按具体开发切片单次申请；代码使用 `device=auto|cpu|cuda`。
- 不直接把完整 `pip freeze` 当作顶层依赖；待依赖选型稳定后生成锁定文件。
- Docker Engine 已从官方 Ubuntu Jammy APT 仓库安装并完成容器运行验证。当前环境无可用 systemd bus，daemon 使用项目专用目录和 Unix socket 手动运行。

当前 Docker 客户端连接变量：

```bash
export DOCKER_HOST=unix:///tmp/supplyagent-docker.sock
```

该 socket 位于 `/tmp`，服务器或任务环境重启后需要重新启动 daemon；不得改成无认证的 TCP 监听。

## 依赖维护约定

1. 直接依赖、实际版本和变更原因统一记录在本文件。
2. 每次安装、升级或删除包，同步更新本文件的日期、原因和验证结果。
3. 如未来需要可复现锁定，由依赖工具生成锁文件，不手工编辑。
4. 禁止把 API Key、服务器绝对路径或本地模型文件写入依赖台账或锁文件。
5. Python模型版本均视为运行时依赖，必须在开发说明中记录。
