## 职责

拥有多维度信息收集的 fan-out 编排与中间产物。节点内部允许 LLM 做有界的观察-判断循环（见 `DECISIONS.md` D01），但不做跨维度的语义归纳（归 Research）。

## 不变量与 contract

- 只做采集编排，不做跨维度语义判断。
- 采集失败必须显式标记，不得用推测内容拼凑摘要。
- 供应商字段映射等实现细节归 Tools 层，不散落进本模块推理逻辑。
- 用便宜快速模型（见 `DECISIONS.md` D06）。
- **供应查询默认只扇出主源，不并发查全部已配置 provider**（见 `DECISIONS.md` D13）。扩展到第二家
  必须命中确定性规则（主源无结果／库存不足／多候选需选型／用户要求比价），由代码判断不由 LLM 裁量；
  阈值取自 `business_rule` 表，不硬编码。真正扇出时并发执行，延迟取最大值而非累加。
- 不同 provider 的结果不合并为单一"市场最优"结论；不同币种／包装不自动混合比较（BR-06）。
