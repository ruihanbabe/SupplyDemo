## 职责

拥有 HTTP 请求 DTO、路由分发、鉴权中间件；把已校验的 HTTP 输入转换为 Supervisor 调用，把内部结果投影为对客户端安全的响应。不拥有业务推理、会话持久化或审批决策。

## 修改前

阅读本目录 `ARCHITECTURE.md`、仓库根 `ARCHITECTURE.md` 的 API 行与「依赖方向」、`DEVELOPMENT.md`；代码与测试待建。

## 不变量与 contract

- 鉴权失败必须拒绝，不得降级放行；业务推理不进入路由层。
- transport 不泄露内部对象、未脱敏 Trace、密钥或上游异常原文。
- 只调用 Supervisor，并将其安全失败投影为对客户端安全的响应。
- 多租户当前仅架构预留（见 `DECISIONS.md` D10），不在本模块提前实现。
