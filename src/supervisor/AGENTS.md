# Supervisor 模块指引

> **文档契约** · 类型：模块入口 · 读取：进入本目录前
> 更新：职责或依赖变化时
> 独占：本目录实现约束
> 不收录：全局架构正文

本模块是会话状态与上下文枢纽，按请求复杂度条件路由并分派 Worker 调用。职责、落点与不变量以根目录 `ARCHITECTURE.md`「一级逻辑模块」为准，依赖方向见同文「依赖方向」。

实现级约束（顶层表未展开的部分）：

- Worker 以可调用工具的形式唤起，返回类型化结果；本模块不解析 Worker 的说明文字，也不重算其数值（BR-20）。
- 路由决策必须留痕：判定依据、选中链路与被跳过的 Worker（FR-13）。
- 路由失败退到最简链路 `Intake → Internal → Report`，不报错终止（FR-13）。
- 本模块不做业务计算、工具执行、上下文编译或长期状态恢复；这些分别属于 Procurement Core、Tool Registry、Context Compiler 与 Run Manager。
