# 事件触发入口

> **文档契约** · 类型：局部架构 · 读取：修改触发入口前
> 更新：触发源、去重语义或退避策略变更时
> 独占：本目录内部文件分工
> 不收录：顶层模块表（见根 `ARCHITECTURE.md`）、告警判定规则（见 `src/alerting/`）、决策理由、当前状态

把用户提交的业务事件（提交 BOM、更新需求、导入库存快照）转换为去重后的 Run 入口，创建与人工入口语义相同的 Run。

**不做定时巡检。**不含模型调用，不判定告警，不绕过人工审批。

| 关注点 | 约定 |
|---|---|
| 去重窗口 | 窗口内同一对象不得创建第二个 Run；新触发并入既有 Run 或显式丢弃并留痕（BR-15） |
| 退避 | 连续失败按退避重试，不得紧循环；失败必须可见 |
| 权限 | 事件入口与人工入口共用同一状态机、权限与证据要求 |
| 预算 | 受 Run 预算约束，超预算显式停止而非截断证据 |

触发源集合与窗口时长见 Q-06。验收见 EV-47。
