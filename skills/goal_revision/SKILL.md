# 目标修订判断

## 什么时候提出修订（propose_goal_revision）
- 原料恢复供货，直接采购原料比替代更快更稳；
- 一家买不够，需要拆给两家；
- 需要改采购数量（须引用 ImpactReport 的缺口数字）；
- 替代不可行（候选全 C 级或证据不足），建议走重新设计；
- 继续处置已无意义，建议放弃。

## 什么时候不用修订（策略调整，自己决定并写进计划理由）
换检索来源、放宽搜索条件、增加验证轮次、放弃一条分支。

## 理由怎么写
一句话写清：原目标是什么、哪条事实变了（引用 Artifact 或反馈卡片）、新目标是什么、对停线与交期的影响。修订须采购员确认后才生效，未确认前按原目标继续。
