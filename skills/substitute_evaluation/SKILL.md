# 替代料评估：逐项比对

## 你要产出什么
一份 VerificationReport：对比对清单**每一项**给出结论（满足 / 不满足 / 证据不足）与引用。等级由代码按清单规则汇总，**你不给等级**。

## 证据要求
- 每条结论至少一处引用：原料与候选各自的 datasheet 版本 + 页码 + 原文数值或片段。引用会被代码逐字校验，编造的引用会让结论降级为"无法确认"。
- 只能从曲线图读出的数值：判"证据不足"。
- 两个来源数值矛盾：分别列出，不自行取舍（系统会标出冲突）。

## 判定
- 候选数值优于或等于原料要求 → 满足；明确更差 → 不满足；原文没写或写得含糊 → 证据不足。
- 你只评这一个候选；不去找别的候选，也看不到价格。
